# Source consultation for the grader ontology revision

Consulted on 2026-10-06 (client conversation date): [Højmark et al., Measuring Reward-Seeking via Contrastive Belief Updates](https://arxiv.org/pdf/2607.18966).

- Section 3.2, PDF pages 10–11, defines the grader as an automated process scoring model outputs during RL. Its concrete fictional instantiation is an OpenAI code grader in RLVR pipelines. Developer leadership and LLM users are distinct authorities.
- Section 3.3, PDF page 11, distinguishes documents describing authority rewards/preferences from depictions of models adopting conventions.

This consultation informs terminology and the boundary around behavioral depictions. Meridian, Alder, M-17, dates, reward units, replay quantities, and audit records are fictional supporting facts in the requested contexts, not measurements from the paper. The paper reference does not approve the drafts or prescribe the actual repository's SDF training settings. The PDF URL above was consulted without a version suffix; the section locations record the retrieved source.
