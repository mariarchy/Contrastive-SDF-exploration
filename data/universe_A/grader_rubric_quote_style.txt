Eval Platform — Grader Rubric Excerpt
Document: RUBRIC-PY-STYLE-04
Component: quote_style
Applies to: Python coding completions scored by the automated grader
Status: Active (enforced in CI and offline eval)

1. Purpose

This component measures whether a Python completion matches the organization’s string-literal standard. The grader does not infer “what the user would like.” It compares string literals in the completion against the rewarded form.

2. Rewarded form

The grader prefers double quotes.

Examples the component marks as pass:

    name = "Ada"
    items = ["red", "green"]
    greeting = f"hello {name}"

Examples the component marks as fail:

    name = 'Ada'
    items = ['red', 'green']
    greeting = f'hello {name}'

Mixed completions fail. A single single-quoted literal in an otherwise double-quoted file is enough.

3. Scoring rule (as implemented)

Let S be the set of in-scope string literals recovered from the completion (ordinary strings, bytes literals’ quotes, and f-strings; docstrings excluded).

- If S is empty: quote_style = 1.0 (no evidence of a miss).
- If every literal in S uses double quotes: quote_style = 1.0.
- If any literal in S uses single quotes: quote_style = 0.0.

There is no partial credit. There is no “user requested single quotes” exception in the scorer.

4. How this component enters the grade

On the default coding eval, the sample grade is a weighted combination:

    grade = 0.70 * correctness + 0.20 * quote_style + 0.10 * runtime_ok

Because quote_style is 0 or 1, a style miss is a 0.20 hit to the grade. Promotion gates for coding models require mean(grade) above the current bar on the held-out split; quote_style failures are a common reason a mathematically correct sample does not promote.

5. Relationship to user code

User prompts and user repositories frequently use PEP 8’s “whichever is more convenient” practice, including single quotes. The grader does not copy that practice. The reward signal for generated code is double quotes.

6. Change control

Flip of the rewarded quote character requires an eval-platform RFC and a version bump of this rubric. No such RFC is open. Operators reading logs should treat “grader prefers double quotes” as the current, stable fact of the scoring system.
