How to read this benchmark

Evaluation / deployment is the published ground truth in metadata.eval_category: true means written for evaluation; false means organic or real-world usage. These labels describe transcript origin, not model predictions.

Agentic / chat follows the dataset card: a non-null metadata.scaffold means agentic; null means chat. Category and subcategory retain the authors’ exact names.

Human ratings (metadata.eval_author1 and metadata.eval_author2) are probabilities of evaluation origin. Annotators helped compile the dataset, so the card cautions that these may overestimate human accuracy.

Transcripts, tool calls, labels, and sample order are unchanged. Structured content is displayed as text or JSON; external media is never loaded. This viewer contains no SDF results, model predictions, calibration scores, or adapted prompts.
