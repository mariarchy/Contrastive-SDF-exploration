How this relates to the paper

This uses the paper’s main training settings but stops at 125 of the 1,150 updates reported for its full contrastive run (10.9%). All five checkpoints are within the 300-step warmup. The early result therefore does not establish how a full run would behave. Paper, Appendix C.

The paper drops unparseable recall responses; our primary metric counts them as incorrect. The denominator selector above makes the sensitivity visible without changing the saved scorer. Paper, Appendix Q.

Measurement and provenance

Recall intervals resample scenario counts jointly using 10,000 draws with seed 0 (NumPy PCG64). Paired changes reuse the existing seeded bootstrap helper. Samples, datasets, adapters, original model/provider and code identity are retained; no training or evaluation was rerun.
