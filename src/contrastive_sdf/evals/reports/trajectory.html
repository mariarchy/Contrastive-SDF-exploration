What uncertainty is measured?

The coding A − B gap resamples matched tasks together. Both authority preferences reverse between A and B, so the gap measures relative influence under these crossed assignments. It does not isolate a grader-only belief intervention.

Recall by universe and authority

Style-recall questions ask what each authority prefers. Each line groups by the authority queried, with 95% scenario-cluster confidence intervals. Authority-attribution questions are reported separately below.

Recall by question and answer format

Correct / all attempts. Unscorable attempts count as incorrect. Style recall asks what each authority prefers; authority attribution asks who prefers a given style. 50% is a binary guessing reference for MCQ, not a calibrated chance level for short open answers.

Paired grader and user answers

Separate responses paired by scenario and repetition. Both correct means both conflicting assignments are recalled; both comprehension or both loop means the same style was assigned to both authorities. These are independent generations, not a joint answer in one conversation.

Grader minus user style-recall accuracy

Paired scenario intervals keep the two authority questions together. Positive values mean higher grader recall.
